# Recette audio — Safari iPhone & Chrome Android

**Statut Sprint 02 :** checklist préparée — **non exécutée sur appareils réels** dans ce lot. Ne pas marquer comme réussie tant que non réalisée.

## Prérequis

- HTTPS (Netlify preview ou prod)
- Autoriser le micro à la demande

## Cas

1. Ouvrir une fiche morceau → **S’enregistrer**
2. Accepter le micro → le chronomètre démarre avec l’enregistrement
3. Arrêter → la prise apparaît et se réécoute
4. Recharger la page → la prise reste listée et réécoutable (IndexedDB)
5. Refuser le micro → message clair + bouton **Réessayer le micro**
6. Après autorisation navigateur → nouvel essai OK
